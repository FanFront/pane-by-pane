# AGENTS.md — Android wrapper guidance

This fork is for **personal, noncommercial, offline Android play** of the
existing pane-by-pane game. Preserve the upstream game logic and web UI.

- Do not rewrite the puzzle engine, generator, solver, rules, board or hints.
- Keep `package.json` and `package-lock.json` compatible with upstream;
  Android build dependencies are installed temporarily by
  `scripts/build-android.sh`.
- Capacitor configuration lives in `capacitor.config.json`.
- The `android/` project is generated by `npx cap add android`, not committed.
- The APK build and download workflow is `.github/workflows/android-apk.yml`.
- Keep the original LICENSE, copyright notice and noncommercial restrictions.
- Run tests, typecheck, web build and the Android debug build after changes.
