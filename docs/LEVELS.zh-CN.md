# 关卡选择与通关记录

从 Android APK 或网页打开游戏，顶部导航栏点击 **关卡**，即可进入关卡选择界面。首次打开、且没有上次游玩记录时，会直接显示此入口，不再自动生成随机题。

## 目录

- **Zone 1 / Zone 2 / Zone 3**：依照上游 `puzzles/official/Zone1`、`Zone2`、`Zone3` 分类。
- **章节**：根据上游文件夹顺序按数字排列，`1-...`、`2-...` …… `10-...`；同一个数字的多个子章节使用自然字符串顺序。
- **关卡**：同一章节内按预设难度从低到高排序（使用原始 `archive_difficulty`，不重新计算）。相同难度按题号自然排序，如 `0008`、`0067`、`0067B`、`0527`。难度星级保留原始数值，不再限制为 7 星；关卡卡片标注星级，较长的星级显示可以滚动。
- **其它**：本地示例与用户自己导入的 JSON 题库仍会保留独立分组，可从同一界面游玩。

Zone 标签和章节卡片会显示 **已完成 / 总关卡数**；每个关卡显示 **✓ 已完成**、**○ 未完成** 或 **◆ 进行中**。点击关卡即可开始游戏，在解题页面使用上一关/下一关切换到按章节顺序与章节内难度排序排列的相邻关卡。

## 存储规则

通关记录存放在本设备的浏览器或 Android WebView 的 `localStorage`，键为 `pbp:level-progress:v1`。每一关使用 **来源 + 路径/题号** 作为稳定 ID，不依赖列表下标，即使题库顺序发生变化仍能识别已完成的题目。

只有玩家实际完成并通过游戏规则验证，才将该题记为已完成。**查看答案不会获得已完成标记**；重复玩已经完成的题，不会清除历史完成记录。玩家每步的格子涂色、画线依旧由既有 `pbp:marks:...` 本地存档保存；重新打开游戏能够继续之前的关卡。

存档位于当前安装/浏览器内部，不会自动上传 GitHub 或跨设备同步。卸载应用、清除应用数据或清除浏览器站点存储会导致本地完成记录丢失。升级同一应用而不清除应用数据时通常会保留记录。

## 随机生成

随机生成并未移除，它现在被放在下方可折叠的 **高级工具：随机生成关卡** 内，避免阻碍主要的官方章节流程。
